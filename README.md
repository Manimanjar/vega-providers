# Vega Providers Repository

Custom extension repository for **[Vega App](https://github.com/vega-org/vega-app)**.

## Available Providers:
- **XVideos** (`xvideos`): Streams and downloads videos directly inside Vega App.

## How to Install in Vega App:
1. Open Vega App > **Providers** > **Add Source** (`+` icon).
2. Enter your GitHub username: `Manimanjar`
3. Tap **Confirm** and install **XVideos**.
